#+title: ZstdLib.jl

Read and write [[https://facebook.github.io/zstd/][Zstandard]] data with [[https://github.com/BioJulia/BufferIO.jl][BufferIO.jl]], with dictionaries for
compressing small data well.

#+begin_src julia
using ZstdLib

# Compress a file
ZstdWriter(open("data.zst", "w"); level = 19) do writer
    write(writer, read("data"))
end

* Comparison with CodecZstd

[[https://github.com/JuliaIO/CodecZstd.jl][CodecZstd.jl]] provides Zstandard codecs for [[https://github.com/JuliaIO/TranscodingStreams.jl][TranscodingStreams.jl]], so it slots in
alongside the other TranscodingStreams codecs, such as CodecZlib and CodecXz.
ZstdLib works on BufferIO's interface instead, like [[https://github.com/tecosaur/XzLib.jl][XzLib]] and [[https://github.com/BioJulia/BGZFLib.jl][BGZFLib]], and adds
dictionaries: training them, compressing with them, and picking the right one
for each frame when decompressing.
